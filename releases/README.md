# LR2 Plus releases

The newest is in `latest/`; the launcher downloads its files from the folder named by its tag.

## v342

- Track editor: its world is now free roam - no race, no game checkpoints, nothing hidden by distance
- Tests load a race and F3 brings you back to the editor's world

## v341

- Track editor: a proper editor screen - menus, tools, panels, palette, dialogs; just your car in its world
- Test your track alone or race it with CPU cars; custom tracks no longer wait for the CPU map

## v340

- Track builder in the main menu: new track (pick the world, start empty or from a copy), edit a saved track, play one
- Every builder screen can be changed with the menu editor (F4)
